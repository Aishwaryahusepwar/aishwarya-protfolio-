# Aishwarya's Portfolio

This is my personal portfolio website created as a beginner-level web development assignment.

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript (ES6+)

## Main Sections

- Home
- About Me
- Education
- Skills
- Experience
- Projects
- Certifications
- Contact

## JavaScript Features

1. Dark Mode / Light Mode button
2. Project filtering using buttons
3. Contact form validation
4. Current year in footer

## How to Run

1. Open the folder in VS Code.
2. Open `index.html`.
3. Use Live Server, or open the HTML file directly in a browser.
4. Internet is needed for the Bootstrap CDN.

## Assignment Requirements

The website uses semantic HTML sections, CSS styling and media queries, Bootstrap components, JavaScript DOM manipulation, project filtering and client-side form validation.

The contact form is only a front-end form for demonstrating validation. It does not send data to a server.


## Project Filter
The project buttons are made with simple JavaScript. The three projects have different categories so that clicking **All**, **AI / ML**, or **Python** visibly changes the projects shown.

- All -> shows all 3 projects
- AI / ML -> shows CareFind and COVID-19 Detection
- Python -> shows CareFind and Visualize Narratives
